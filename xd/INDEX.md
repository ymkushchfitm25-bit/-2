# Завдання з програмування на Python

Колекція програм для демонстрації основних концепцій структур даних та об'єктно-орієнтованого програмування у Python.

## Структура проекту

### Завдання 1: Операції зі списками
**list_operations.py** - Демонстрація індексування, зрізування і модифікації списків
- Звернення за додатними та від'ємними індексами
- Три різних типи зрізів (базовий, з кроком, зворотний)
- П'ять операцій модифікації на місті (append, insert, remove, del, slice assignment)

### Завдання 2: Роботи з кортежами
**tuples_collection.py** - Роботи з кортежами, розпакування, мутабельні вкладені об'єкти
- Розпакування та індексація кортежів
- Агрегація по колекціям кортежів
- Демонстрація іммутабельності та мутабельності вложених об'єктів

### Завдання 3: Словник частот
**word_frequency_dict.py** - Побудова словника частот слів/символів без collections.Counter
- Нормалізація тексту (слова та символи)
- Побудова словника явним циклом (без Counter)
- Dict comprehension для фільтрації
- Сортування за ключем та по частоті

### Завдання 4: Операції над множинами
**sets_operations.py** - Перетин, об'єднання, різниця, симетрична різниця, підмножини
- Вхідних колекцій з повторами
- Перетин (intersection), об'єднання (union)
- Різниця та симетрична різниця
- Перевірка підмножини (subset)
- Порівняння множини та списку

### Завдання 5: Порівняння продуктивності
**performance_comparison.py** - Вимірювання часу операцій на різних розмірах даних
- Пошук у списку vs множині
- Перевірка ключа у словнику
- Побудова унікальних значень
- Таблиці результатів з асимптотичною складністю

### Завдання 6: Ієрархія класів (OOP)
**vehicle_hierarchy.py** - Предметна область "Транспортні засоби" з поліморфізмом
- Базовий клас Vehicle
- 4 підкласи: Car, Motorcycle, Truck, Boat
- Поліморфний обхід колекції об'єктів
- Перевірка типів (isinstance, issubclass)

### Завдання 7: Магічні методи
**vector_magic_methods.py** - Клас Vector3D з операціями над векторами
- Представлення (__str__, __repr__)
- Арифметика (__add__, __sub__, __mul__, __truediv__, __neg__)
- Порівняння (__eq__, __lt__, __le__, __gt__, __ge__)
- Контейнер (__len__, __getitem__, __setitem__, __abs__)
- Таблиця магічних методів і їх операторів

## Запуск програм

```bash
python list_operations.py
python tuples_collection.py
python word_frequency_dict.py
python sets_operations.py
python performance_comparison.py
python vehicle_hierarchy.py
python vector_magic_methods.py
```

## Вимоги

- Python 3.6 або новіше
- Жодних зовнішніх бібліотек не потребується
